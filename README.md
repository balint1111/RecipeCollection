# RecipeCollection (Kotlin + Spring Boot)

This project has been rewritten as a Kotlin Spring Boot application using Hibernate (JPA), MapStruct, and Jackson.

## Requirements
- JDK 21
- Gradle 8+

## Run locally
```bash
./gradlew bootRun
```

The API will be available at `http://localhost:8080`.

## Example endpoints
- `GET /api/recipes`
- `POST /api/recipes`
- `GET /api/materials`
- `POST /api/materials`
